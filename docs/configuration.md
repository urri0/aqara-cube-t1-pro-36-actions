# Configuration

## Initial setup

Enter your actual Zigbee2MQTT topic:

```text
zigbee2mqtt/<friendly_name>
```

Mark sides already handled by external YAML/scripts as External.

## Options

Open integration options to configure each side:

```text
Side mode: External / Managed / Disabled
Profile: Media / Light / Climate / Custom
Entity: primary entity
Secondary entity: optional script/scene/entity
Custom overrides: optional JSON action fields
```
